# Site

Páginas estáticas da consulta pública. Cores, espaços e tipo estão em [css/tokens.css](css/tokens.css), no padrão de [.cursor/skills/using-ui-stack.md](../../.cursor/skills/using-ui-stack.md).

As páginas ainda não leem dados. `site/dados/` reserva o lugar da cópia publicada de `dados/organizado/`.

## Abrir no navegador

Dentro desta pasta:

```
python -m http.server
```

Acesse http://localhost:8000/ e percorra a capa, Cidade, Políticos e Metodologia.
